# envi-releases

Official release downloads for [Envi](https://envi.mavos.org), a desktop
translation tool published by MAVOS Company Limited.

- Binaries only. The Envi source code lives in a separate private repository.
- Download from the [Releases](../../releases) page or via the canonical
  origin `https://releases.envi.mavos.org`.
- Artifact filenames are content-addressed: the SHA-256 digest is part of the
  filename, so a given filename always identifies the same bytes.
- Windows updates are signed and verified by the Envi updater before install.

Support: support@mavos.org
